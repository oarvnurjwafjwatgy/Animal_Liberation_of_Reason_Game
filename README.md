Ver.2======================================================================================================
※6月現在スキルの正しい攻撃値の受け渡しがなく、通常攻撃の威力で放っていたため修正いたしました。
==========================================================================================================
キャラごとに特徴を出したかったので、以下のような特徴にしております。

・ライオン
爆発強化型：スキルではバフ掛けすることができ、5秒間攻撃力の上昇。
専用ゲージが満タンで理性開放をすると一時的に速度強化のバフを付与。
圧倒的な攻撃力を持ちますが、その反面攻撃回転率は一番遅いのでタイミングが重要です。防御力もあまりないので注意。

~~「変更箇所」~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
元々速度の上昇でしか輝くことができない特性で折角ダメージを喰らって発動させたのに
技の回転が遅いこともあり、理性開放の使いにくさや逆転要素が薄いキャラでした。
より戦いやすい状態にするため特性の一部を変更しました。

特性：速度上昇数秒後発動
➡速度上昇＆受けるダメージのしきい値を大幅に超えるとその分超過で攻撃値が上乗せされるよう変更。
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

・ダチョウ
体力温存・攻撃回転型：スキルでは蹴りを放ち（攻撃）、理性開放をすると解放状態時のみ毎時最大HPの2％回復と、
通常攻撃・スキルの回転率は他キャラよりも早い。しかし防御力とHPは少ないため、駆け引きが大事。

~~「変更箇所」~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
主に攻撃の回転率で勝負するスピードキャラとして君臨していたのですが、
スキルがシンプルな蹴り攻撃の割にはCTがあまりにも長く、攻撃力も雀の涙のレベルでした。
（上記にも記載しましたが、スキル用の攻撃値が通常攻撃の状態だったため。）
より楽しく走って何度も攻撃してほしいと願い以下のように調整しました。

スキルの攻撃値上昇：理性開放
発動前の倍率1.9f
発動後の倍率2.5f
※各動物のスキル発動倍率の中でトップです。（攻撃値が一番低いので）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

・サイ
守り・戦略型：スキルでは理性開放ゲージを消費しながら、爆速で突進することができる。
しかし使いすぎては負けてしまうので注意。
他キャラでは存在するクールタイムはこのキャラにはない。（スキルのみ）
戦況をひっくり返す・返されるのも自分の判断次第になります。

~「バグ&修正報告」~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
元々爆速で理性ゲージを減っていました。
ブラッシュアップの際、改めてコードを見ると0.1fに1回分に設定されており使いにくい技だと発覚しました。
現在は1秒に5ずつ減るように設定・速度の変更に伴い、より使いやすいスキルへと調整致しました。
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

・ラーテル
特殊・バランス型：スキルでは穴を掘って、潜ることが可能です。
相手に奇襲をしかけ飛び出し攻撃をしたり、通常攻撃の速さはダチョウの次に早いバランスタイプです。
ただし潜った状態で攻撃されるとひるんで穴から出てしまうため注意。
攻撃力も防御も速度も体力も基本的なので、使いやすいキャラになっています。



--4-3.　Animal Reason Battleについて。--------------------------------------------------------------------------------------
Animal Reason Battleは理性ゲージ（青）やHPといった二つのゲージを切り替えながら戦う3Ð対戦アクションゲームです。


「通常状態」と「理性開放状態」

本作品では、この2つのモード切替を自在に操り最後の一人になるまで戦うゲームになっております。
通常状態ゲージ・理性ゲージのどちらかが0になった瞬間その人はバトル終了になってしまいます。


「違い」

・通常状態は理性ゲージを削ることなく素で攻撃することができます。
　※ダメージを受けていたのなら少しずつ理性ゲージが回復します。

・理性開放状態では理性ゲージを少しずつ消費しながら一気に勝負に出る状態になっており、
HP上昇・理性ゲージ上昇を除く、素のステータスよりも大幅にステータスが上昇し、キャラクターによって上昇する部分は異なります。

ライオン➡主に攻撃力を主体とするステータスアップ、他は微強化。
ダチョウ➡主に速度を主体とするステータスアップ、他は微強化。
サイ　　➡主に防御を主体とするステータスアップ、他は微強化。
ラーテル➡主に全体をバランス的にステータスアップします。

4-4.【最新版】 プログラム設計のブラッシュアップ（2026年6月実施）
本作は一通りの機能実装が完了した後、さらにクオリティの高い、運用のしやすいコードへ成長させること、
および多人数開発に耐えうる設計力を証明することを目的に、大幅なプログラムの再構築（リファクタリング）を行いました。

直面した課題：主に自分がメインの担当箇所であるCharacter_Statusへの機能集中（密結合）/////////////////////
初期の実装では、ゲームの心臓部である Character_Status に以下のすべての処理が詰め込まれており、
コードが肥大化して見通しが悪い状態になっていました。
・HP管理 / 理性管理 / 移動速度・攻撃力の管理
・ダメージ処理 / 回復処理 / 死亡・奈落死処理
・モード管理（通常・強化） / モードチェンジ処理
・各動物の固有ロジックやスキル・UIの呼び出し　　　　　等
この状態では、新しい動物を追加するたびにメインコードを書き換える必要があり、バグを誘発しやすい状態でした。
また、他の人が見ても読みにくいコードになっていたり、数か月後にコードを見ても自分で書いたものでも
分かりにくさが目立っていました。
////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////////

「ブラッシュアップによる変化」
データとロジックの分離、および役割を小分けにすることを意識し、以下の3点について改善を行いました。

・各動物の処理を「継承」によって完全分離/マジックナンバーの削除
元々CharacterStatusに書いてあった各動物の処理を共通基盤となるものは抽象クラス Animal_Skill_TraitBase を新設し、
各動物（ライオン、ダチョウ、サイ、ラーテル）のスキルや特性はすべて子クラスへ分離しました。
メインコードを一切汚さずに、新しい動物をいくらでも追加できる拡張性を確保しました。
また、元変数であった本来定数にしなくてはならないものまで雑にコードのいたるところに存在してましたが、
全てCharacterDataから呼び出すように改良。
また、定数を全て動物ごとのstructで管理し、パラメーターを全てそこへ集約させました。
（「パラメーターの一元管理」）

・木の実（アイテム）処理の単一責任化
他クラス（CharacterStatusに存在した処理）と複雑に絡み合っていた木の実の効果や消滅タイマーを Nuts クラス自身に集約。
データ（NutsData）とロジックを切り離し、アイテム単体で自己完結して動くスマートな設計に修正しました。

・パラメータデータの一元管理（CharacterDataの新設）
スクリプト内に散らばっていた最大HPや速度倍率、タイマー初期値などを新設した CharacterData クラスへ完全集約しました。
ゲームバランスの数値調整を行う際、ソースコードを探索することなく一箇所で安全に変更できるようになりました。

動くだけのコードから、チーム開発や長期運用を見据えた一級品のコードへと自身の技術をブラッシュアップさせた実績となります。
